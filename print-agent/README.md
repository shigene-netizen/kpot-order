# print-agent — 厨房打单代理

跑在**店里那台常开的 Windows 电脑**上的小程序。它只做一件事：

```
问云端「有厨房单吗？」 → 有就取下来 → 通过 TCP 9100 发给打印机 → 回报结果
```

> **安装步骤看 [`PRINT-AGENT-SETUP.md`](./PRINT-AGENT-SETUP.md)**，这份文件只讲原理。

---

## 文件

| 文件 | 作用 |
|---|---|
| `agent.js` | 程序本体。约 270 行，**零依赖**，只用 Node 内置模块。 |
| `config.example.json` | 配置模板。复制成 `config.json` 再填。 |
| `start.bat` | 双击启动。会先检查 Node 有没有装。 |
| `config.json` | **你自己填的那份，不进版本库**（含 printKey）。 |

## 为什么需要它

订单服务器跑在云端，打印机在店里的局域网上。**互联网够不着店里的打印机**，
所以必须由店内的一台机器主动去取单。这样就：

- 不用在路由器上开端口；
- 不用固定公网 IP；
- 打印机换 IP 只改这一台电脑的配置，不用动云端。

## 为什么它这么「笨」

它**不知道**票据长什么样，**不读**菜单，**不做**任何判断——只搬字节。

所有排版都在**服务器**的 `printer.js` 里做。所以改票据版式（加个字段、
换个纸宽）**永远不需要碰店里这台机器**。这一点是刻意设计的：
店里那台电脑是最难远程维护的东西，让它尽量少变。

## 零依赖

只用 Node 内置的 `fs` / `path` / `net` / `http` / `https`。
**不需要 `npm install`**，所以不会出现装依赖失败的问题。

HTTP 请求故意用内置的 `http`/`https` 而不是全局 `fetch`：
`fetch` 要 Node 18+ 才有，而店里电脑装的是什么版本说不准。

## 它怎么判断「打成功了」

网络收据打印机（9100 端口）**几乎不给反馈**：收下数据就关连接，
没有「打印完成」这种回复。所以判定规则是：

- 写到一半连接断了 → **失败**，会重试；
- 字节全部写完 → **成功**。

把「写完但没收到确认」当失败的话，服务器会重发，
厨房就会拿到**两张一样的单子**。宁可偶尔漏报一次，也不要重复打。

> 所以看板上的 `PRINTED` 准确含义是「数据已全部发出」，不是
> 「机器传感器确认纸出来了」。纸用完了这种情况它**看不出来**——
> 这就是为什么看板上要保留 **Reprint** 按钮。

## 排队是「租借」式的

```
电脑取走一张单  →  租借 2 分钟  →  打完回报「好了」
```

电脑要是中途崩了，租借到期，这张单**自动回到队列**。
所以一台电脑崩掉**不会吞掉订单**，换台机器接着打就行。

## 它怎么知道云端在哪（地址会变，所以不能写死）

点餐网站**每次重新发布都会换一个新地址**。如果把这个地址写进这台电脑的
`config.json`，那每次发布完都得跑一趟店里改文件——**忘了改，打印就静默停摆**。

所以地址是**查来的**，不是配的：

```
[GitHub Pages 转发页]  ← 地址永远不变，二维码就印它
        │  上面写着网站的当前地址
        ↓
[这台电脑]  每 5 分钟读一次；连不上或收到 400 就立刻再读一次
```

三个刻意的设计：

1. **剥注释再匹配。** 「注释掉旧地址、把新地址粘在下面」是最自然的改法，
   直接匹配第一个 `baseUrl:` 会**悄悄跟着旧地址跑**——症状只是「不打单了」。
2. **查不到不清空。** 转发页抽风不是停止打印的理由，继续用当前地址。
3. **收到 400 立刻重查。** 重新发布后旧地址就是这个反应，不用等下一个周期。

想固定死地址：`discoveryUrl` 填 `""`，再填 `serverUrl`。

## 环境变量（测试用，会覆盖 config.json）

`KPOT_SERVER_URL`、`KPOT_DISCOVERY_URL`、`KPOT_DISCOVERY_MS`、
`KPOT_DISCOVERY_MINUTES`、`KPOT_PRINT_KEY`、`KPOT_PRINTER_HOST`、
`KPOT_PRINTER_PORT`、`KPOT_POLL_MS`、`KPOT_PRINT_TIMEOUT`

自动化测试就是靠这些变量驱动这个程序的，不需要动真的 `config.json`。

> ⚠️ `KPOT_DISCOVERY_URL=''` 是**真的关掉**自动查地址（代码用
> `hasOwnProperty` 判断，不是 `||`）。别的测试套件靠这一条保持**不联网**——
> 如果哪天改成 `||`，它们会悄悄跑去访问 GitHub Pages。
