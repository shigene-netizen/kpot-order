# 给打印机绑固定 IP（彻底治好「突然不打了」）

> 这份文档是给**店里**用的。操作都在店内那台跑 `start.bat` 的 Windows 电脑上做。
> 全程**不花钱**，只需要路由器的管理密码（通常贴在路由器背面的贴纸上）。

---

## ⚠️ 本店实际情况（先看这段，下面的通用例子以本店为准）

- **代理电脑（跑 `start.bat` 的那台）IP：`192.168.68.100`**
- **打印机 IP：`192.168.68.102`，端口 `9100`**（已确认可达、能连）
- **路由器：TP-Link Deco** —— 这台型号**没有「地址预留 / DHCP 保留」功能**，

## 第 0.5 步：先部署新版代理，清掉 `CAN NOT FOUND SERVER ADDRESS`

店里代理窗口现在报的错误是 `CAN NOT FOUND SERVER ADDRESS`（不是超时）。
原因：旧版代理没跟上我们网址从 `github.io` 跳到 `www.kpotexpress.com` 的 301 跳转。
新版代理已经修好，并且把服务器网址**直接钉死**在配置里，不再依赖跳转。

在店里电脑（192.168.68.100）上做：

1. 把我给的 **`kpot-print-agent.zip`** 解压，**覆盖**到原来的 `print-agent` 文件夹
   （里面已经带好钉死网址的 `config.json`，`printerHost` 就是 `192.168.68.102`，不用改）。
2. 关掉原来那个黑窗口，双击 `start.bat` 重新开。
3. 看黑窗口：应该出现 `-> https://order.kpotexpress.com`，**不再**报 CAN NOT FOUND。
4. 打开管理后台 → **Orders** → 找一张付过款的单 → 点 **🖨 Reprint**。
   - 出纸 / 窗口出现 `printed` → ✅ 这一关过了，再回来做下面的静态 IP。
   - 还是 `FAILED ... timed out ... 192.168.68.102:9100` → 打印机或网线问题，往下看第 1 步。
   - 出现 `401` → 配置里的 `printKey` 不对（一般不用动）。

## 先说清楚为什么是这件事

> 下面用**通用例子**解释「超时 / 拒绝」两种报错的含义，方便你对照看板红条。
> 本店**当前的**报错是 `CAN NOT FOUND SERVER ADDRESS`（已在第 0.5 步处理），
> 本店打印机实际 IP 是 `192.168.68.102`，不是下面例子里的 `192.168.1.50`。

看板上那个红条写的是：

```
timed out after 0/965 bytes — tried 192.168.1.50:9100
```

这句话有两个信息，都很关键：

| 看到什么 | 意思 |
|---|---|
| `timed out`（超时） | 那个地址上**根本没有任何设备回应** |
| `refused`（拒绝） | 设备在的，但端口没开（打印机开着但没吃纸/型号不对） |
| 末尾的 `192.168.1.50` | 代理**现在**在打这个地址 |

超时 ≈ 路由器重启过后，打印机被分到了**另一个 IP**，`192.168.1.50` 就空了。
所以「绑固定 IP」是对症的：绑完之后这个 IP 永远归这台打印机，不会再变。

## 第 0 步：先确认打印机本身还活着

在打印机上打一张**自检页**（最常见的方法：**关机 → 按住 FEED 进纸键不放 → 开机**，
出纸后松手）。

自检页上会印出：

- 它**现在的 IP**（可能已经不是 `192.168.1.50` 了）
- 通常是它的 **MAC 地址**（形如 `00:11:22:33:44:55`）
- 型号

**用手机拍一张自检页。** 后面要对着填。

> 如果自检页上的 IP 是 `169.254.x.x` 开头的：那不是「拿到新 IP」，
> 是**打印机根本没连上网络**（没连上 WiFi / 网线掉了 / WiFi 密码改过）。
> 这种情况绑 IP 没用，得先让它连上网。

## 第 1 步：查出这台电脑在哪个网段（2 分钟）

**在店里电脑上跑我们准备好的脚本**（不用懂，照抄）：

1. 键盘按 `Win` 键，输入 `powershell`，回车
2. 蓝色窗口里先粘这一行回车（只做一次，窗口关掉就失效，安全）：

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   ```

3. 用 `cd` 进到 `print-agent` 文件夹，例如：

   ```powershell
   cd "C:\Users\你的用户名\Desktop\print-agent"
   ```

   > 不确定在哪：**资源管理器里找到 `start.bat` → 地址栏复制路径**，
   > 粘到 `cd "` 后面的引号里。

4. 粘这一行回车：

   ```powershell
   .\find-printer.ps1
   ```

它会打出四件事：

```
IP address      : 192.168.68.100      <- 电脑自己（本店）
Default gateway : 192.168.68.1        <- 这就是 Deco，浏览器里输它
Wifi network    : KPOT-Shop           <- 电脑连的 WiFi 名
FOUND: 192.168.68.102:9100 is open    <- 打印机现在在这儿！（如果扫到）
```

**记下三样东西**：网关地址（路由器）、WiFi 名、脚本扫出来的打印机 IP（如果有）。

> 脚本会扫整个网段找开了 9100 端口的设备 —— 热敏打印机基本是店里唯一开这个端口的东西。
> 就算 IP 变了也能把它揪出来。

**如果脚本说「Nothing on this network is listening on 9100」**：

- 打印机没开机 / 网线松了 / WiFi 没连上 → 先解决这个
- 打印机连的是**访客 WiFi** 或者**另一个路由器** → 访客网会把设备互相隔离，
  绑 IP 也没用。必须让它和电脑**连同一个 WiFi 名**
- 打印机是 **USB 连电脑**的，不是网口 → 那要走 Windows 打印机共享，
  这条路另说，先告诉我

> ⚠️ **一个容易漏的检查**：如果自检页上的 IP 是 `192.168.0.x`，
> 而电脑是 `192.168.1.x` —— 它们**不在同一个网段**，
> 说明店里有两个路由器。这种情况要告诉我，先解决网络结构，别急着绑 IP。

## 第 2 步：进路由器，把 IP 绑给打印机

浏览器地址栏输入**第 1 步查到的网关地址**（常见是 `192.168.1.1` 或 `10.0.0.1`），回车。

登录账号密码通常在**路由器背面的贴纸**上。ISP 的机器（Xfinity / AT&T / Spectrum）
第一次登录会让你设一个，或者用贴纸上的 `admin` / `password`。

进去之后，找这些词里的任意一个（不同品牌叫法不一样，**但意思都一样**）：

| 你在界面上看到 | 常见位置 |
|---|---|
| **Connected Devices** / **Attached Devices** / **Device List** | 首页或 Advanced |
| **DHCP Reservation** / **Reserved IP** / **Address Reservation** | LAN / Network / DHCP Server |
| **IP Allocation** / **Static Lease** / **Manual Assignment** | Home Network / LAN Setup |

**通用做法**（所有品牌都一样）：

1. 先打开**设备列表**，在列表里找你的打印机
   - 名字里常常带品牌或型号：`EPSON`、`TM-T88`、`XP-`、`Star`、`POS`
   - 认不出来就**对 MAC**：和自检页上那串 `00:11:22:...` 比对
2. 点它 → 找 **Reserve / Reserve IP / Add Reservation / Make Static**
3. 在 IP 那一栏填一个**固定的数字**，例如 `192.168.1.50`
4. **保存 / Apply / Save Settings**

### 各品牌入口速查

| 路由器 | 管理地址 | 在哪设置 |
|---|---|---|
| **Xfinity / Comcast** | `10.0.0.1` | 登录 → Connection → **Local IP Network**；或用 xFi App：设备 → **Reserve IP** |
| **AT&T (BGW210 / BGW320)** | `192.168.1.254` | Home Network → **IP Allocation** → 选设备 → 设为静态 |
| **Spectrum** | `192.168.1.1` | Advanced → LAN → **DHCP Reservations**（部分型号没有，见下方备选） |
| **Netgear** | `192.168.1.1` / `routerlogin.net` | Advanced → Setup → LAN Setup → **Address Reservation** → Add |
| **TP-Link（普通路由器）** | `192.168.0.1` / `tplinkwifi.net` | Advanced → Network → DHCP Server → **Address Reservation** |
| **TP-Link Deco（本店）** | Deco App | ⚠️ **本店这台 Deco 没有「地址预留」**，App 里也找不到 → **不能在这绑，直接看文末「备选方案」去打印机身上设静态 IP** |
| **Asus** | `router.asus.com` | LAN → DHCP Server → **Enable manual assignment** |
| **Linksys** | `192.168.1.1` | Connectivity → Local Network → **DHCP Reservations** |
| **Google / Nest Wifi** | Google Home App | Wifi → 设备 → **保留 IP**（Reserved IP） |
| **Eero** | Eero App | Settings → Advanced → **DHCP & NAT** → Reservations |

### 该绑哪个 IP？

> **本店是 Deco，没有地址预留功能，所以这整节「在路由器上绑」对本店不适用。**
> 本店直接跳到文末「备选方案：路由器不给绑怎么办」，去**打印机身上设静态 IP**。
> 下面这段只对**有** DHCP 保留功能的普通路由器有效，留着备查。

如果有保留功能，建议就绑 `192.168.68.102` —— 代理配置里现在写的就是这个，
绑成它的话 `config.json` 一行都不用改。

> 如果你的网段不是 `192.168.68.x`（比如 Xfinity 常见 `10.0.0.x`），
> 那就绑 **`10.0.0.50`**，然后 `config.json` 里也要改成 `10.0.0.50`。
> **两处必须一模一样。**

## 第 3 步：让打印机重新拿 IP

绑完不会自己生效，得让打印机**重新申请一次**：

1. **打印机断电** → 等 10 秒 → 通电
2. 等 30 秒（让它连网、拿到 IP）
3. 再打一张**自检页**，确认上面印的 IP **就是**你刚绑的那个

自检页上的 IP 还是不对 → 多半是 MAC 填错了，回到第 2 步核对。

## 第 4 步：在电脑上验证（不验证别往下走）

回到蓝色 PowerShell 窗口：

```powershell
ping 192.168.68.102
```

（把 IP 换成你绑的那个）

- 看到 `Reply from 192.168.68.102` → ✅ 打印机在
- 看到 `Request timed out` → ❌ 还没通，回第 3 步

再确认端口（热敏打印机走 9100）：

```powershell
.\find-printer.ps1 -TargetIP 192.168.68.102
```

看到 `RESULT: OPEN. Something IS listening on 9100 there.` 就是**完全通了**。

## 第 5 步：改 `config.json`

用**记事本**打开 `print-agent` 文件夹里的 `config.json`。

```json
{
  "printerHost": "192.168.1.50",
  "printerPort": 9100,
  "printKey": "...",
  ...
}
```

- `printerHost` → 改成第 2 步绑死、第 3 步确认过的那个 IP
- `printerPort` → 不用动，几乎所有热敏打印机都是 `9100`

### `printKey` 要不要改？

**只在代理窗口里出现 `401` / `unauthorized` 时才改。**
如果代理已经在报 `timed out ... tried 192.168.1.50:9100`，
说明它**已经成功从服务器拿到单子了**，钥匙是对的 —— **别动它**。

改的话：取服务器上 `/etc/kpot.env` 里 `PRINT_KEY=` 后面的值，
原样粘进 `printKey`。

## 常见坑

| 现象 | 原因 |
|---|---|
| 自检页 IP 是 `169.254.x.x` | 打印机没连上网（不是 IP 变了） |
| ping 不通，但路由器设备列表里有它 | 它在**访客 WiFi** 上，被隔离了 |
| 绑完重启，IP 还是老的 | 打印机上被设过**自己的静态 IP**（在打印机里设的），那个优先级比路由器的保留更高 —— 二选一，别两边都设 |
| 隔几个月又不打了 | 换了路由器/光猫 → 网段可能变（比如 `192.168.1` 变 `10.0.0`），`config.json` 要跟着改 |
| 自检页 IP 和电脑不在同一段 | 店里有两个路由器，先解决网络结构 |

### 备选方案：路由器不给绑怎么办（**本店就是这种情况 —— Deco 没有保留功能**）

反过来：**在打印机自己身上设静态 IP**。这样不管 Deco 怎么分 IP，打印机永远用 `192.168.68.102`。

⚠️ **别用浏览器开 `http://192.168.68.102` 设 IP** —— 那个管理网页是**密码锁住的（401）**，
常见默认账号密码（admin/1234、admin/admin、root/root … 18 组）都试过，全不对。

> **本店打印机实测情报**（我这边直接探过它的网页）：
> 网页标题是 **「Toast Printer Configuration」**，服务器是 `webnet (RT-Thread)`，
> 这是一款**很通用的国产热敏打印机网络模块**（很多白牌 58/80mm 小票机都用它），
> **出厂默认 IP 是 `192.168.1.251`**（网页里的链接写死了这个地址）。
> 当前 IP 被改成 `192.168.68.102` 说明有人配过，但**网页密码被改过 / 不常见**才 401。
> 所以设 IP 有**两条路**，下面都给。

#### 第 1 步：确认打印机品牌 / 型号（走「方法一」才需要）

工具是按品牌分的，所以先认牌子。两个办法，任选：

1. **打一张自检页**：关机 → 按住 **FEED 进纸键**不放 → 开机 → 出纸后松手。
   纸上会印 **型号**（比如 `XP-80C`、`ZT-58`、`TM-T88IV`）和 **MAC 地址**。
2. **看机器身上的标签**：翻到打印机底部或后盖，铭牌上有品牌和型号。

> 不管外面贴什么牌，里面的网络模块都是上面那个 **Toast 模块**，
> 所以「方法一」下载工具时，认准**打印机外面的品牌**去官网下即可。

---

### 方法一（推荐，不用动电脑 IP）：用厂商 Windows 配置工具

#### 第 2 步：下对应品牌的配置工具，装到店里电脑（192.168.68.100）

> **已确认（店主拍了自检页）**：打印机型号 **Toast TP200**（TP200 / TP200W），
> 固件 `FV2.038.03`。如果能找到 Toast 官方的 `Toast Printer Setting Tool`
> （问卖打印机的店要、或 Google 搜 `Toast TP200 setting tool`），优先走方法一。
> 拿不到就**直接走方法二**，不依赖任何工具。

| 品牌 | 工具名（去官网「支持 / 下载」找） |
|---|---|
| **Toast**（本店已确认 TP200） | `Toast Printer Setting Tool`（问卖家或搜官网） |
| **Xprinter 芯烨** | `Printer Setting Tool`（有时叫 `XP-58/80 Setting Tool`） |
| **Zywell 智微** | `Zywell Printer Setting Tool` |
| **Gprinter 佳博** | `GP Printer Setting Tool` |
| **Epson** | `EpsonNet Config` |
| **Star** | `Star Net Utility` |

（拿不准就先试 Xprinter 的 `Printer Setting Tool`，覆盖面最广；白牌机通常就是它。
把自检页上的型号发我，我也能帮你定位确切的工具下载地址。）

#### 第 3 步：用工具把打印机设成静态 IP

1. 店里电脑连上和打印机**同一个 WiFi / 同一个网**（本店都是 `192.168.68.x`）。
2. 打开刚装的工具 → 它会**自动扫描局域网里的打印机**，列出当前 IP（应该是 `192.168.68.102`）。
3. 选中它 → 找到 **IP / Network / Ethernet** 设置，改成：
   - **IP Address：`192.168.68.102`**（就是要固定的这个）
   - **Subnet Mask（子网掩码）：`255.255.255.0`**
   - **Default Gateway（网关）：`192.168.68.1`**（Deco 的地址；拿不准就用 `find-printer.ps1` 查出来的网关）
   - **DHCP：关掉 / 改成 Static / Manual**
4. 点 **Apply / 应用 / 设置**，工具会提示重启打印机 → 照做（或手动断电 10 秒再通电）。
5. 再打一张**自检页**，确认印出来的 IP 就是 `192.168.68.102`。

#### 第 4 步：确认通了

回到 PowerShell：

```powershell
ping 192.168.68.102
.\find-printer.ps1 -TargetIP 192.168.68.102
```

看到 `Reply from 192.168.68.102` 和 `RESULT: OPEN ... 9100` 就是**彻底固定好了**。

> 因为 `config.json` 里 `printerHost` 本来就是 `192.168.68.102`，
> 所以这步**不用改配置**，重启一下 `start.bat` 即可。
> 之后哪怕 Deco 重启、打印机断电，IP 都不再变 → 不会再失联。

### 方法二（不挑品牌，肯定能用，但要动一下电脑 IP）：硬件复位 + 网页设

如果找不到对应工具，或者工具扫不到打印机，就用这个。**原理**：把模块**复位到出厂**，
出厂 IP 变回 `192.168.1.251`、网页密码也变回出厂默认 → 这时就能进网页设静态 IP 了。

#### 第 A 步：复位网络模块

- 找打印机上的 **复位键 / 小孔（RESET）**，通常在网口旁边或后盖里面。
- **通电状态下**用牙签长按 **5–10 秒**，看到指示灯快闪或重启即可松手。
  （一般只复位**网络**，不丢打印内容；个别机型会复位全部，复位前先打一张自检页留底。）

#### 第 B 步：让店里电脑临时够得着 `192.168.1.251`

复位后打印机 IP 变成 `192.168.1.251`，和店里 `192.168.68.x` 不在一段 → 电脑直接打不开。
临时把店里电脑改成同段：

1. 网络和共享中心 → 以太网/WiFi → 属性 → IPv4 → **手动**：
   - IP：`192.168.1.100`（随便挑个不冲突的）
   - 掩码：`255.255.255.0`
   - 网关：留空或 `192.168.1.1`
2. 浏览器开 `http://192.168.1.251` → 登录（Toast 这类 RT-Thread 模块的**出厂默认账号是 `admin`，密码通常是 `1234`**；不对就试 `admin` / `admin`）。

#### 第 C 步：在网页里设静态 IP

进 **Network / IP 设置** → 把获取方式从 DHCP 改成 **Static / Manual**，填：

- **IP Address：`192.168.68.102`**
- **Subnet Mask：`255.255.255.0`**
- **Default Gateway：`192.168.68.1`**
- 保存 → 打印机重启。

#### 第 D 步：把电脑 IP 改回去

把第 B 步的 IPv4 改回 **自动获取（DHCP）**，电脑重新拿到 `192.168.68.x`。
然后 `ping 192.168.68.102` + `.\find-printer.ps1 -TargetIP 192.168.68.102` 确认通了。

> 走完方法二，打印机 IP 就被钉死成 `192.168.68.102`，和 `config.json` 一致，重启 `start.bat` 即可。
