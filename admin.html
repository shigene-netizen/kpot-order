    💳 Turn on card payments

    No Stripe product is ever needed. Two routes — pick one.
    The project ships with server.js. It creates the Stripe session itself, so the guest's total is filled in automatically and nothing needs to be pasted into config.js.
    1. Create a free account at stripe.com
    2. Dashboard → Developers → API keys → copy the Secret key (sk_live_…) or a restricted key (rk_live_…). A restricted key must allow Checkout Sessions: Write and Read — nothing else is needed.
    3. In the project folder: cp secrets.local.json.example secrets.local.json
    4. Paste the key into secrets.local.json
    5. Start with npm start instead of a static file server
    These are not separate choices on your ordering page. Stripe adds them inside its own card form, and only when the guest's device supports them (Apple Pay needs Safari/iPhone; Google Pay needs Chrome + a saved card). So a phone that doesn't have a wallet set up will never show the button — that is normal, not a bug.
    To actually switch them on:
    1. Stripe Dashboard → Settings → Payment methods
    2. Under Wallets, turn Apple Pay and Google Pay ON for the mode you are using (Test and Live are separate!)
    3. Apple Pay only: Settings → Payment method domains → add & verify your site's domain. Apple requires a domain association file, or the button stays hidden on the web even when the toggle is on.
    4. Reload the ordering page and open the payment step.
    The check asks your own server to create a $1 test session and reports the payment methods Stripe actually offered. Nothing is charged.
    1. Dashboard → Payment Links → + New
    2. At "Select a product or service", pick "Customers choose what to pay" — do not add a product
    3. Title it KPOT To Go, currency USD, set a min and max
    4. Create link → copy it and paste it below
    5. Paste into CONFIG.payment.stripe.paymentLink in assets/config.js
    On this route the guest types the amount, so the checkout screen shows the total in large type with a one-tap Copy button.
    If the checkout service lives elsewhere, set CONFIG.payment.stripe.createSessionUrl to its full URL. The app POSTs the order JSON and expects { url } back.
